# Общая память проекта

Память хранится в репозитории, чтобы новый агент или аккаунт мог продолжить работу без доступа к предыдущему чату. Эти файлы нужно передавать и синхронизировать вместе с проектом.

| Файл | Что хранить | Когда обновлять |
| --- | --- | --- |
| [CURRENT.md](CURRENT.md) | Актуальный этап, ограничения, вопросы и ближайшее продолжение | Когда изменилось состояние проекта |
| [TASKS.md](TASKS.md) | Задачи, исполнители, области изменений и статус | Перед работой, при изменении статуса и при завершении |
| [LOG.md](LOG.md) | Короткие записи о завершённой работе и проверках | В конце содержательной сессии |
| [handoffs](handoffs/README.md) | Самодостаточная передача незавершённой задачи | При смене исполнителя или остановке незавершённой работы |

Устойчивое описание проекта хранится в [CONTEXT.md](../CONTEXT.md), существенные решения — в [docs/decisions](../docs/decisions/README.md). Не создавать параллельные версии текущего статуса в личных файлах агентов.

## Как обновлять

1. Перечитать актуальный файл перед изменением и сохранить чужие записи.
2. Записать проверенные факты. Предположения и вопросы обозначить явно.
3. Добавить ссылки на связанные файлы и задачи вместо копирования подробностей.
4. Обновлять общие файлы последовательно; при независимых копиях сначала согласовать и синхронизировать изменения.
5. В журнал добавлять новые записи в конец. Старые записи исправлять только с явным пояснением ошибки; актуальный статус поддерживать в `CURRENT.md`.

Не сохранять полные чаты, скрытые рассуждения, секреты и персональные данные. Память должна объяснять результат и следующие действия, а не воспроизводить процесс размышлений.
