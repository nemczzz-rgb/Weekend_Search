# Передача TASK-016: локальный HTTPS

- Дата: 2026-11-09.
- От: codex/https-local.
- Кому: следующий исполнитель.
- Статус задачи: На проверке.
- Ветка и коммит: Git не настроен.

## Цель и границы

Пользователь попросил HTTPS для сайта. Ранее согласованы локальный выпуск и бюджет 0 ₽; публичное размещение не поручено. Пользователь отдельно отказался добавлять локальный сертификат в доверенные сертификаты Windows.

## Сделано

- Добавлен Windows-скрипт `scripts/local-https/setup.ps1`, создающий сертификат для `localhost` и `127.0.0.1`. PFX и пароль находятся в `%LOCALAPPDATA%\WeekendSearch\https`, вне проекта.
- Vite использует сертификат только в режиме `pnpm dev:https`. Основной `pnpm dev` оставлен по HTTP для совместной правки во встроенном браузере.
- Запущены HTTP на `127.0.0.1:5173` и HTTPS на `127.0.0.1:5174`. README обновлён. При попытке `-Trust` Windows отменил импорт сертификата; повторно действие не предпринималось после отказа пользователя.

## Проверки

- Оба адреса ответили HTTP 200 и вернули одинаковую страницу. Дополнительно Node-клиент проверил HTTPS с явным доверием только к публичному сертификату этого сайта: `status=200 authorized=true`. Системное доверие не менялось после отказа пользователя.
- `pnpm --dir apps/web build` прошёл. Сертификат содержит SAN для `localhost`, `127.0.0.1` и `::1`.
- Встроенный браузер отверг HTTPS с `ERR_CERT_AUTHORITY_INVALID`; HTTP-страница восстановлена и видна.

## Что осталось

Если пользователь позже захочет HTTPS без предупреждения, потребуется его новое разрешение на доверие **этому** сертификату или другой согласованный способ получения доверенного сертификата. Для телефона сертификат и доступ по домашней сети потребуют отдельной настройки. До тех пор рабочий просмотр остаётся по HTTP.

## Блокеры и вопросы

HTTPS технически работает, но не открывается во встроенном браузере из-за недоверенного сертификата. Пользователь выбрал оставить его недоверенным; предупреждение не обходить.

## Решения и контекст

[ADR-001](../../docs/decisions/ADR-001-local-demo-stack.md) закрепляет локальный выпуск. TASK-003 по живым интеграциям остаётся заблокированной; HTTPS-просмотр не меняет её статус.
