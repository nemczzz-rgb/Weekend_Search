# Передача TASK-015: Пересмотр карты

- Дата: 2026-11-09.
- От: codex/integration-review.
- Кому: не назначен.
- Статус задачи: На проверке.
- Ветка и коммит: Git не настроен.

## Цель и границы

Пользователь хочет полноценный локальный сайт с реальной картой и пешим/общественным проездом при нулевом бюджете. Контрольная точка TASK-003 запрещает начинать TASK-004–013 до доказанных интеграций.

## Сделано

Проверены [условия Яндекса](https://yandex.ru/dev/commercial/doc/ru/): бесплатная версия требует общедоступного интернет-проекта и не подходит локальному выпуску. Пользователь выбрал локальный выпуск и 0 ₽; [ADR-003](../../docs/decisions/ADR-003-local-map-reassessment.md) согласована как направление. Обновлены отчёт, ТЗ, план и инструкции, добавлены диагностические скрипты и карта OSM. Большие выгрузки, Java и граф сохранены только в игнорируемой `.local/`. Git не настроен.

## Проверки

Повторный KudaGo-запрос вернул HTTP 403. Официальные московские наборы 60661–60666 проверены: наземный транспорт, 17 850 остановок и 10,8 млн строк времени; 5,3 млн строк не имеют соответствующего рейса в выгрузке другой даты. Временный GTFS для 2026-11-14: 824 маршрута, 81 369 рейсов, 2,13 млн строк. OTP 2.10.0 с Java 25 построил граф за 5 мин 18 с на этом компьютере; локальный сервер вернул и показал на карте пеший путь и автобус м90. Пешая линия следует улицам, автобусная условна без shapes. Физический телефон и полнота проезда не проверены. Подробности: [отчёт](../../docs/architecture/integration-report.md).

18 диагностических unittest и `py_compile` прошли; endpoint вернул оба режима, 46 локальных ссылок в изменённых документах разрешаются. Пробные серверы остановлены после проверки. Интерфейс Vite запущен отдельно на `http://127.0.0.1:5173/`.

## Что осталось

Найти и проверить точную геометрию наземных линий и источник метро либо согласовать ограниченный объём транспорта. Проверить качество расписаний и атрибуцию официальных данных, затем выполнить пробный прогон на физическом телефоне в домашней сети. Устранить KudaGo 403 либо согласовать замену источника каталога. Только затем переоценить TASK-003.

## Блокеры и вопросы

Бесплатный Яндекс API противоречит локальному выпуску; направление заменено по выбору пользователя. Компьютер справился с пробным OTP, но шесть доступных наборов не включают метро и shapes, а версии таблиц расходятся. KudaGo по-прежнему возвращает 403. Если точное покрытие нельзя обеспечить без изменения ТЗ, требуется согласование объёма продукта.

## Решения и контекст

[ADR-002](../../docs/decisions/ADR-002-integration-gate.md) остаётся согласованной контрольной точкой. ADR-003 согласована как направление, но движок ещё не утверждён как окончательный.
