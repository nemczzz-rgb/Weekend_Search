# Передача работы

Для незавершённой задачи скопировать [TEMPLATE.md](TEMPLATE.md) в `YYYY-MM-DD-TASK-NNN-short-title.md` и добавить ссылку в [TASKS.md](../TASKS.md).

Передача должна позволять другому исполнителю продолжить работу без истории чата. Не включать секреты или полную переписку. Для завершённых задач достаточно статуса, журнала и ссылок на результат; отдельная передача не обязательна.

При наличии Git указывать ветку и коммит, если они существуют. Незакоммиченные изменения перечислить явно: одна только ссылка на ветку их не передаёт. Если Git не настроен, указать, какие актуальные файлы нужно передать.
