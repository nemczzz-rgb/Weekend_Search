# ADR-001: Бесплатное локальное демо и стек

- Дата: 2026-11-08.
- Статус: Согласовано.
- Автор фиксации: codex/coordinator.
- Задача: TASK-002.
- Основание: пользователь выбрал React/TypeScript/Vite + Python/FastAPI + SQLite, светлый городской стиль, домашний сервер и затем явно поручил реализацию полного плана.

## Решение

Диалоговый планировщик для жителей Москвы: каталог и индивидуальные маршруты на один/два дня, пешком и на общественном транспорте. Район задаёт начало. Доступны полное редактирование точек, пересчёт и конфликты.

SQLite и приложение локальные. У самостоятельных участников свои экземпляры и Codex; устройства владельца подключаются к одному серверу домашней сети. Аккаунт сайта необязателен, личные планы приватны.

Дополнительный бюджет — 0 рублей. Бесплатные ключи разрешены, платные API и автосписания исключены. Публичный хостинг, покупки и бронирование не входят в первую версию.

## Варианты и последствия

Пользователь предпочёл Python-бэкенд единому TypeScript-стеку, диалог — основному экрану с картой, домашний сервер — облачной синхронизации и переносу файлами.

Python/TypeScript согласуются через OpenAPI. Для межустройственного доступа сервер должен работать. Публичное обслуживание через общий аккаунт Codex из этого решения не следует.
