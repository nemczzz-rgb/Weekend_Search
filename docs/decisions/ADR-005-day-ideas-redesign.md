# ADR-005: «Идеи для дня» и развитие утверждённого дизайна

- Дата: 2026-11-12
- Статус: Согласовано
- Автор: nemczzz-rgb/codex
- Связанная задача: TASK-034, [#5](https://github.com/nemczzz-rgb/Weekend_Search/issues/5)
- Основание: владелица 12.11.2026 выбрала доработку утверждённого дизайна без полной замены и подтвердила общую основу остальных решений D2–D15. Alex071004 утвердил D2–D15 12.11.2026 («да мы это утверждаем», PR #4) и подтвердил изменённый D1 13.11.2026 («Да, подтверждаю»).
- Заменяет / заменено: нет

## Контекст

План «Идеи для дня» предлагал полный редизайн. Владелица попросила сохранять утверждённую версию отдельно и развивать её, чтобы можно было вернуться к исходнику. Снимок подготовлен в [PR #32](https://github.com/nemczzz-rgb/Weekend_Search/pull/32) и 13.11.2026 слит в `main` (папки `design/approved/` и `design/iterations/`).

## Варианты

1. Полностью заменить оформление всех страниц. Это противоречит последнему выбору владелицы.
2. Сохранить утверждённый визуальный язык, доработать существующие страницы и добавить новые экраны. Это выбранное владелицей направление.

## Решение

**D1.** Утверждённый дизайн остаётся основой. Главную, места, маршруты, план и ввод пожеланий улучшаем по результатам UX-аудита; новые экраны «Идеи для дня» встраиваем в тот же стиль. Полная замена оформления не входит в задачу. Снимок утверждённой версии остаётся отдельно от рабочих изменений.

Остальные решения из [раздела 4 плана](../project/day-ideas-plan.md#4-решения-по-умолчанию-утверждаются-на-воротах-g0) согласованы обоими участниками:

| ID | Направление |
| --- | --- |
| D2–D5 | Статическая база знаний; без встроенного ИИ; план в браузере; перестановка кнопками |
| D6–D8 | События с датой и источником; фильмы и рецепт владелицы в основе базы; остальные материалы с проверкой источников |
| D9–D10 | Иллюстрации по мере необходимости; без встроенной карты, с проверенными ссылками на адреса |
| D11–D13 | Отдельная ветка разработки; адрес Sites пока заморожен; свободные локальные шрифты |
| D14–D15 | Минимальные объёмы базы знаний из плана; название вкладки выбирается на этапе UX |

Детальные формулировки D2–D15 — в разделе 4 плана; там же D13 уточнён: переносятся шрифты утверждённого дизайна. Для G0 остаётся схема базы знаний и валидатор в `main` (TASK-035).

## Последствия и проверка

- UX-аудит и концепты должны исходить из существующего сайта и явно отмечать, какие элементы улучшены или добавлены.
- Новые экраны не должны требовать полной смены визуального языка.
- Изменения интерфейса остаются в отдельной ветке до приёмки; `main` продолжает показывать утверждённую версию.
- Снимок `design/approved/` — эталон для аудита (TASK-037) и приёмки макетов (TASK-042); непринятые варианты хранятся в `design/iterations/`.
