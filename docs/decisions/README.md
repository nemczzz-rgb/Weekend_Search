# Журнал решений

Здесь фиксируются существенные продуктовые и технические решения вместе с причинами, альтернативами и последствиями. Обычные действия в рамках задачи достаточно отражать в журнале работы.

Для нового решения скопировать [TEMPLATE.md](TEMPLATE.md) в файл `ADR-NNN-short-title.md`, выбрав следующий свободный номер. Допустимые статусы: `Предложено`, `Согласовано`, `Отклонено`, `Заменено`.

Статус `Согласовано` требует явного основания: поручения или подтверждения пользователя либо ранее предоставленных полномочий для такого решения. Ссылку на недоступный чат нужно дополнять кратким самодостаточным изложением подтверждения. Секреты и приватную переписку не копировать.

При замене решения сохранить старый файл и сослаться на новое решение. Новые записи добавлять в индекс ниже.
