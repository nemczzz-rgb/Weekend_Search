# ADR-002: Контрольная точка бесплатных интеграций

- Дата: 2026-11-08.
- Статус: Согласовано.
- Автор фиксации: codex/coordinator.
- Задачи: TASK-002, TASK-003.
- Основание: явное поручение пользователя реализовать план с обязательной TASK-003 до основной разработки.

## Решение

Источник: KudaGo API. Помощник: локальный Codex App Server через Python и stdin/stdout. Кандидат карты и проезда: JavaScript API Яндекс Карт 2.1.

До TASK-004–013 подтвердить живой импорт, поиск Codex, ограничения его инструментов, бесплатную карту и оба режима проезда на компьютере и физическом телефоне. Установленный CLI и найденная документация не заменяют проверку.

Для проверки разрешены диагностические скрипты и страница, а не основное приложение. Ключи и токены не записываются в отслеживаемые файлы, отчёт и вывод. Ответы карты не сохраняются в постоянную базу.

## Исходы

- Все пункты доказаны: можно начинать основу приложения.
- Нет входа, ключа или телефона: проверка незавершена; указать конкретное действие, не объявлять сервис несовместимым.
- Есть воспроизводимая несовместимость: вернуть на пересмотр ТЗ, не подменять моками, приблизительной навигацией или платным API.

Помощник не получает shell, репозиторий и личные коннекторы. Детали: [ТЗ](../project/technical-specification.md), [план](../project/implementation-plan.md).
