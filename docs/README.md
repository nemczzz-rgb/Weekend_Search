# Карта документации

| Раздел | Назначение |
| --- | --- |
| [project](project/README.md) | Требования, границы продукта и будущий согласованный план |
| [decisions](decisions/README.md) | Решения, альтернативы и причины выбора |
| [architecture](architecture/README.md) | Структура системы, модели данных и контракты |
| [design-system](design-system/README.md) | Визуальные правила и компоненты |
| [testing](testing/README.md) | Стратегия проверки и критерии качества |
| [deployment](deployment/README.md) | Окружения, выпуск и восстановление |

Разделы подготовлены для следующих этапов, их содержимое пока не является планом реализации. Оперативная память хранится отдельно в [memory](../memory/README.md).

Документы называть по содержанию, например `requirements.md` или `data-model.md`. Для существенных решений использовать нумерацию `ADR-001-short-title.md`. Даты записывать в формате `YYYY-MM-DD`, время при необходимости — с часовым поясом.
