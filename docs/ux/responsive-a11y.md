# Адаптивность и доступность

Цель — WCAG 2.2 уровня AA (AC-DI-12). Проверка — в макетах (TASK-042) и в коде (TASK-052).

## Ширины экрана

| Ширина | Навигация | Сетка | Особенности |
| --- | --- | --- | --- |
| 360 | Нижняя панель, 4 пункта (или «Город», см. [IA](information-architecture.md#меню)) | 1 колонка | Минимальная поддерживаемая ширина; ни одного горизонтального скролла страницы |
| 390 | Нижняя панель | 1 колонка | Основная мобильная ширина макетов |
| 768 | Шапка с меню | 2 колонки карточек | Нижней панели нет |
| 1024 | Шапка | 2–3 колонки | S03 уже в две колонки |
| 1280 | Шапка | 3 колонки | Основная десктопная ширина макетов |
| 1440 | Шапка | 3 колонки, контент не шире 1260 px | Башня по-прежнему справа |

- Горизонтальной прокрутки страницы нет ни на одной ширине. Ряды чипов переносятся на новые строки, а не уезжают вбок.
- Нижняя панель не закрывает контент: у страницы нижний отступ не меньше высоты панели плюс 16 px. Уведомления появляются над панелью.
- На 390 px при фокусе в поле пожелания страница прокручивается так, чтобы поле и кнопка отправки были над клавиатурой. Чипы-примеры могут уйти под клавиатуру — это допустимо.
- Масштаб текста 200 % не ломает раскладку: текст переносится, ничего не обрезается.

## Области нажатия

- Каждая кнопка, ссылка, чип, сегмент и пункт меню — не меньше 44 × 44 px (аудит: сейчас в плане меньше 44 px 33 элемента из 45). Если видимый элемент меньше, увеличивается область нажатия, а не шрифт.
- Между соседними кнопками пункта плана — не меньше 8 px.

## Клавиатура и фокус

- Порядок фокуса совпадает с визуальным порядком сверху вниз, слева направо.
- Видимый фокус — как сейчас (`:focus-visible`), контраст обводки с фоном не меньше 3:1.
- Ссылка «Перейти к содержимому» первой в порядке фокуса.
- Переход вперёд переносит фокус на заголовок `h1` нового экрана (с `tabindex="-1"`) и прокручивает наверх; возврат по истории — фокус на `h1` с `preventScroll`, прокрутка восстанавливается (R-NAV-1).
- Диалоги S08: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок. Фокус при открытии — на «Отмена» (разрушающие кнопки не получают фокус первыми), `Esc` = «Отмена», фокус не выходит из диалога. После закрытия фокус возвращается на вызвавшую кнопку, а если её больше нет (пункт удалён или заменён) — на заголовок затронутого пункта или дня.
- Уведомления: после «Убрать» фокус переходит на «Отменить» в уведомлении (R-DEL-2). Остальные уведомления фокус не забирают и объявляются через `role="status"`; таймер 8 с стоит, пока на уведомлении фокус или курсор.
- Перестановка — R-MOVE-2: фокус остаётся на кнопке, позиция объявляется (`item.position.live`).
- Замена (R-REPL-1): после выбора фокус на заголовке нового пункта.

## Роли и подписи

| Элемент | Разметка |
| --- | --- |
| Меню | `nav` с `aria-label="Основная навигация"`, активный пункт `aria-current="page"` |
| Сегменты «Вид» | группа радиокнопок (`fieldset` + `input type="radio"`) |
| «Тема» в S04 | нативный `select` с `label` |
| Чипы «Для кого», жанры | кнопки с `aria-pressed` |
| Раскрывающиеся блоки рецепта | кнопка-заголовок с `aria-expanded` и `aria-controls` |
| Карточка идеи | одна ссылка на всю карточку; внутри нет других интерактивных элементов |
| Статус «сегодня» | текст, значок с `aria-hidden="true"` |
| Уведомления | одна область `role="status"` (`aria-live="polite"`) на экран |
| Ошибки загрузки | `role="alert"` |
| Пункты плана | `ol` со `li`; `aria-label` кнопок начинается с видимого текста (WCAG 2.5.3): «Выше: Третьяковская галерея» (`item.*.aria`) |
| Поле пожелания | `label` «Что хочется?», подсказка связана через `aria-describedby` |
| Внешние ссылки | `target="_blank"`, `rel="noopener noreferrer"`, стрелка ↗ только у них, для диктора — `common.external.aria` |
| Внутренние переходы | стрелка →, открываются в той же вкладке |

## Цвет и контраст

- Текст — контраст не меньше 4.5:1, крупный текст и значки — 3:1. Пары цветов проверяются по токенам в TASK-040.
- Цвет не единственный носитель смысла: статус «сегодня», прошедшее событие, выбранный фильтр отмечены текстом или значком.

## Движение

- При `prefers-reduced-motion: reduce` башня статична (как сейчас), раскрытие блоков и появление уведомлений без анимации.
- Анимации не дольше 250 мс, ничего не мигает чаще трёх раз в секунду.

## Язык

- `lang="ru"` у документа. Языка оригинального названия фильма в данных нет, поэтому отдельный `lang` у `originalTitle` не ставится.
