# TASK-049 — экраны «Идеи для дня»

Статус: реализация на проверке, общий выпуск G4/G5 и арт-приёмка не заявлены. Экспорт: `DayIdeasScreen` из `apps/web/src/screens/day-ideas/index.ts`. Хост TASK-050 передаёт единый и уже инициализированный `PlanStore`; источник по умолчанию — `getContentSource()`, для API/проверки можно передать `source`. Нового хранилища в экранах нет.

## Что реализовано

- Каталог 40 идей: вид, несколько аудиторий (хотя бы одна подходит всем занятиям), границы времени <120 /120–240/>240 минут, сброс; одна ссылка на карточке, статус, время, первые три потребности.
- Подробный сценарий: исходный порядок занятий, полный список потребностей, подтверждённые факты городских мест и источники. При отсутствии записи — «Пока нет данных»; отсутствующее занятие не позволяет добавить неполный сценарий.
- Статус подготовки пиццы до кнопки, постоянная строка для слишком ранней даты. Время и предупреждение берутся из TASK-047, не из отдельной эвристики экрана.
- Авторский рецепт: исходные разделы/количества, 390 г воды, советы, начинки, подача; ингредиенты открыты, остальные закрыты; «Раскрыть все / Свернуть все». Длительность и температура шагов показаны, если есть в данных.
- Десять жанров, до выбора фильмы не загружаются и не показываются. Первые шесть, затем ещё шесть; owner раньше research, внутри — новые годы первыми. Подлинный локальный постер, мини-описание, все источники и даты; ошибка изображения оставляет название/год/выбор. Пропорции сохранены, object-fit:contain, lazy/async.
- Выбор фильма временный до добавления, после добавления сразу меняет настоящий PlanStore; повторное нажатие снимает выбор, смена жанра очищает прежний фильм.
- Добавление без перехода: один/два дня, часть уже в плане, всё уже в плане, дубли, лимит «всё или ничего», предложение другого дня, отмена ровно добавленных uid. Уведомление 8 с с паузой при фокусе/наведении, ошибка сохранения не выдаётся за успех хранения.
- Query-параметры view/idea/mode/for/time/genre; фильтры заменяют запись истории, переход создаёт новую. Назад возвращает фильтры/прокрутку, фокус на h1 без дополнительной прокрутки. Хост может задать `history.state.from = {href,label}` для возврата на главную/план.
- Адаптивная сводка справа 380px на 1280, на телефоне кнопка в начале и конце; изображения только при наличии image, BASE_URL и srcset 640/1280. Коллекции только через ContentSource; loading/error/retry, unknown id и пустая база.

## Интеграция

Ветка создана от свежего main; обычным merge включены `origin/redesign` (TASK-047, PR #61) и TASK-048 (PR #63), без переписывания истории. Поэтому итоговый PR в main содержит готовые зависимости. Можно интегрировать ту же ветку в redesign для общего выпуска; разрешения на публикацию не было.

`App.tsx` не меняется: глобальная маршрутизация и запуск общего store принадлежат TASK-050. Хост отображает `<DayIdeasScreen store={store} />` при `view=day-ideas`. Дев-просмотр `?ideas-preview=1&view=day-ideas` использует настоящий store с отдельным ключом предпросмотра и не входит в production. Ссылки на план/места/главную в нём демонстрируют адреса хоста, а не реализацию TASK-050. Полный путь от опубликованной главной и общий вес первого экрана проверяются после интеграции хоста.

При браузерной проверке найден дефект TASK-047: import JSON с атрибутом type:json получает от Vite JS-MIME в dev. В vite.config.ts точечно удаляются options этих динамических импортов только у content/static-source.ts для браузерного преобразования. Исходник адаптера сохранён: Node 24 продолжает исполнять JSON с обязательными атрибутами. Проверены Node-тесты, браузер и production build без предупреждений.

## Известное ограничение логотипа

Официальный URL найден в шапке [документации TMDB](https://developer.themoviedb.org/docs/faq): https://files.readme.io/29c6fee-blue_short.svg. Локальная загрузка не прошла (TLS/таймаут, в том числе Edge), поэтому в разделе «Источники и атрибуция» используется **этот официальный внешний URL**, без выдуманного знака. При ошибке изображение скрывается, текстовая ссылка TMDB и требуемое уведомление остаются. Автономная локальная копия знака — незавершённый пункт, пока источник недоступен. Собственные постеры не зависят от этого сервера и уже локальные.

Атрибуция и формулировка соответствуют [FAQ поставщика](https://developer.themoviedb.org/docs/faq); изображения не объявлены свободной собственностью проекта. Платные API/вход не использовались.
