## 2. Устройство сейчас

Три экрана без адресов: состояние `view` в памяти страницы, URL не меняется.

```
Главная ──► Каталог (вкладки «Идеи 34» / «Места 45») ──► План (1–2 дня)
   │              │ «Взять за основу» / «В план +»           ▲
   └─ 6 подборок ─┴──────────── «Открыть идею» ─────────────┘
```

- **Навигация:** на десктопе — шапка «Идеи / Места / Мой план», на телефоне — плавающая нижняя панель с теми же кнопками.
- **Главная:** постер «Выходные в Москве», две кнопки, 6 первых идей.
- **Каталог:** одна страница с двумя вкладками, поиск, фильтр тем (только у идей).
- **План:** заголовок (название идеи или «Мой план»), свёрнутые «Настройки и подбор по пожеланию», баннер «Черновик», сводка, переключатель дней, карточка дня с пунктами, форма «Добавь своё место».
- Данные — 45 мест и 34 маршрута из базы знаний (TASK-035). План живёт только до перезагрузки.

## 4. Проблемы по приоритету

**П1 — мешают основной задаче ТЗ**
1. Подбор по пожеланию спрятан: план → свёрнутый блок → поле. Пользователь его почти не найдёт.
2. «Открыть идею» и «Взять за основу» сразу заменяют план. Просмотра идеи до решения нет, а ТЗ требует путь «выбор → подробный план → в мой день».
3. Нет адресов экранов: «Назад» уводит с сайта, экраном не поделиться.
4. План пропадает при перезагрузке.
5. В плане могут быть только места: нет места для домашних занятий и дня без маршрута.

**П2 — заметно ухудшают опыт**
1. Много элементов меньше 44 px: на телефоне в каталоге мест — 86 из 138, в плане — 33 из 45.
2. Каталог мест на телефоне — 17 700 px прокрутки (45 длинных карточек), группировки и фильтров нет.
3. 20 тем-фильтров у идей, нет фильтров ТЗ (дома/город, для кого, время).
4. Удаление без отмены, системное `confirm` при замене плана.
5. Смешанный тон: «Найдите место», «Выбирай места», «Укажите название», «ТЫ НАПИСАЛ».
6. Уведомление показывается дважды; «Живой помощник будет подключён позже» — обещание вне плана.

**П3 — мелочи**
1. «14 Ноября» с заглавной буквы.
2. Одна дата «Проверено 10.11.2026» для всех фактов.
3. Шесть подборок на главной — просто первые шесть в файле.

## 7. Что это значит для вариантов развития (TASK-038)

- Нужно решить, где живут «Идеи для дня»: вкладка рядом, раздел каталога или общий каталог идей с фильтром «дома / в городе / вместе». Плюс новые названия (D15).
- У любой идеи должен появиться экран просмотра до добавления в план, а «в мой день» — стать отдельным действием.
- Поле пожелания должно стать видимым входом: на главной, в плане или в обоих местах.
- План должен показывать разные виды пунктов (место, событие, занятие, свой пункт) и домашний день без адресов.
- Сохранить: постер, башню, редакционную нумерацию, честные карточки фактов, нижнюю панель на телефоне, перестановку кнопками.
