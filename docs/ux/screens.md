# Экраны

Для каждого экрана описаны:
- назначение;
- блоки сверху вниз на 390 px, а отличия на 1280 px — отдельно;
- откуда берутся данные (поле базы знаний → место на экране);
- действия и состояния.

Стиль — как сейчас (ADR-005). Названия компонентов («Карточка идеи», «Блок статуса», «Пункт плана» и т. д.) переходят в `docs/design-system/brief/components.md` (TASK-040). Тексты — ключи из [microcopy.md](microcopy.md), правила — ID из [interaction-rules.md](interaction-rules.md).

Общие состояния всех экранов с данными базы знаний (P1, загрузка асинхронная):
- **Загрузка** — скелет карточек в стиле сайта, без вращающихся индикаторов. На Pages почти не виден.
- **Не удалось загрузить** — `common.loading.error` и кнопка `common.reload`.

Иллюстрации (D9, TASK-051) — только когда у записи есть `image`. Слот: верх карточки идеи и маршрута, над заголовком S03 и S05, пропорция 3:2. Без `image` слот не резервируется.

## S03. Идея для дня (подробно)

**Назначение:** понять сценарий целиком и добавить его в день.

Блоки 390 px:

1. Ссылка «←» по R-NAV-2.
2. Иллюстрация (если есть), рубрика `idea.kicker`, заголовок, `summary`.
3. Строка «Для кого · Время». «Для кого» — общая аудитория всех занятий через запятую («Вдвоём, с друзьями»); если общей аудитории нет — строка без неё.
4. **Блок статуса** «сегодня» (R-TODAY-2). При `lead.min > 0` — развёрнутое предупреждение: заголовок «Начать за ‹срок›» и текст `idea.lead.text` с `leadTimeNote`. Стоит **выше** первой кнопки (AC-DI-04).
5. Кнопка «В мой день» по R-ADD-2 и R-ADD-7. Под ней, если день ближе срока подготовки, — постоянная строка R-TODAY-4.
6. «Что понадобится» — полный список `needs` без повторов.
7. Занятия по порядку, курсивные номера `01`, `02`, `03`. У каждого рубрика `‹NN› / ‹НАЗВАНИЕ ЗАНЯТИЯ›`, время и содержимое по `detail.type`:
   - `recipe` — блок «Рецепт»;
   - `films` — блок «Фильм»;
   - `steps` — нумерованный список шагов;
   - `places` — компактные карточки мест: название, адрес-ссылка (content-rules «Факты»), плашки «Часы / Стоимость», источник.
8. Вторая кнопка «В мой день» (только 390 px).

**Блок «Рецепт»** (`recipes.json`):
- Строка `recipe.yield` и источник: для `source: "owner"` — `recipe.source.owner`, иначе `recipe.source.web` с доменом.
- Раскрывающиеся блоки по порядку:
  - «Ингредиенты» — открыт по умолчанию; группы, строки по content-rules «Рецепт»;
  - разделы `sections` с номером и заголовком **как в данных** («3. Брожение — 48–72 ч в холодильнике»): срок уже в заголовке раздела, отдельно он не добавляется;
  - «Советы», «Начинки», «Подача» — только если они есть в данных.
- Шаг: текст; если есть `durationMinutes` или `temperatureC`, после текста серым — «· 20 мин», «· 250 °C».
- Начинка: название жирным, текст после тире.
- Кнопка `recipe.expandAll` / `recipe.collapseAll`.

**Блок «Фильм»** (`films.json`):
- `film.chooseGenre` — 10 чипов, переносятся на строки; выбран один жанр или ни одного (R-FILM-1).
- После выбора — до 6 строк с постером и «Название · год», порядок по R-FILM-2, кнопка `film.more`. Постер вертикальный, пропорции сохранены; при его недоступности остаётся текст. Источник и атрибуция — по R-FILM-4.
- У каждой строки кнопка `film.choose` / `film.chosen` (R-FILM-3).
- Подпись `film.note`.
- Жанр без фильмов — `film.empty`.

**1280 px:** две колонки. Слева блоки 1–3 и 6–7. Справа — липкая карточка-сводка: для кого, время, блок статуса, «Что понадобится» (первые 5), кнопки «В мой день» и строка R-TODAY-4. Вторая кнопка внизу не нужна. Фильмы — в две колонки.

**Состояния:**
- кнопка в состояниях R-ADD-7;
- занятие ссылается на рецепт, которого нет, — в этом блоке `idea.noData`, остальное работает.

## S06. Места

| Блок | Содержимое |
| --- | --- |
| Вводная | `places.kicker`, `places.title`, `places.subtitle` |
| Ближайшие события | По R-EVENT-1. Карточка события: название, дата и время, место (ссылка на `?view=places&place=<id>`) или адрес, цена, «Источник ↗ · Проверено ‹дата›», кнопки по R-EVENT-2. Сначала 6, `events.all` раскрывает остальные на месте |
| Поиск | Как сейчас |
| Список | Карточка места — как сейчас: даты «Проверено» по content-rules «Факты»; `hints` без строки «Проверено»; кнопка `places.add` |

- Фильтра по виду места в v1 нет: в базе 24 вида на 45 мест, фильтр почти не сокращал бы список. Проблема П2.2 аудита (длинный список на телефоне) в v1 не решается и остаётся в бэклоге.
- Параметр `place=<id>` прокручивает к карточке места и подсвечивает её на 2 с (без анимации при `reduced-motion`).

**1280 px:** две колонки, как сейчас.

**Состояния:**
- нет событий — блок скрыт;
- нет мест под поиск — `places.empty`.

## S07. Мой план

Блоки сверху вниз:

1. `plan.kicker`, заголовок `sourceTitle` или `plan.title`, подзаголовок `plan.subtitle`.
2. Баннер «Даты плана прошли» по R-DAYS-4 — если нужно.
3. **«Что хочется?»** — поле пожелания и чипы-примеры.
   - Если в плане есть пункты, блок свёрнут в строку `plan.wish.collapsed` с кнопкой «Изменить».
   - После подбора под полем — `plan.youWrote`; после перезагрузки этой строки нет (R-MODEL-2).
4. **«Уточнить»** (свёрнуто): район начала, дата первого дня (не раньше сегодня), «Один день / Два дня». Время начала и окончания и 12 интересов **убраны** (вопрос 15, раздел 1.7 вариантов).
5. Строка хранения: `plan.storage` или `plan.storage.off`, кнопки `plan.export`, `plan.import`, `plan.clear`.
6. Сводка `plan.summary` и переключатель дней `plan.daySwitch` (если дней 2).
7. Для каждого дня:
   - баннер «Черновик»: домашний или обычный (R-DAYS-5);
   - строка подготовки R-TODAY-3 — если нужно;
   - карточка дня: номер, «суббота, 14 ноября» (строчными), `plan.day.start` по R-DAYS-5;
   - пункты дня. Перед первым домашним занятием, если перед ним есть городские пункты, — рубрика `plan.eveningHome`.
8. Кнопки добавления `plan.add.place` (→ S06), `plan.add.idea` (→ S02), `plan.add.custom` (форма: название — обязательно, адрес, минуты; пустое название — кнопка неактивна, подсказка `custom.titleRequired`).

**Пункт плана** — четыре вида:

| Вид | Показывает | Кнопки |
| --- | --- | --- |
| Место | Как сейчас: вид · район, название, описание, адрес-ссылка, «Часы / Стоимость», источник, `item.duration` | Выше, Ниже, В другой день, Заменить, Убрать |
| Событие | `item.kind.event`, название, дата и время, место или адрес, цена, источник; состояния R-EVENT-3 | Выше, Ниже, В другой день (R-MOVE-4), Убрать |
| Занятие | `item.kind.activityHome` или `item.kind.activityCity`, название, что понадобится, `item.duration`, `item.genre` (если выбран). У городского занятия с `detail.places` — список его мест: название и адрес-ссылка. Кнопка `item.openIdea` → S03 по `ideaId` | Выше, Ниже, В другой день, Убрать |
| Свой пункт | `item.kind.custom`, название, адрес текстом (без ссылки на карту), `item.duration` | Выше, Ниже, В другой день, Убрать |

**1280 px:** колонка пунктов шириной как сейчас; кнопки пункта в одну строку; блок добавления — справа от сводки.

**Состояния:**
- пустой план — блок «Что хочется?» с чипами как главное содержимое и текст `plan.empty` с кнопками к идеям, маршрутам и местам;
- пустой день при непустом плане — `plan.emptyDay` и кнопки добавления;
- хранилище недоступно — `plan.storage.off`;
- пункт ссылается на удалённую из базы запись — R-SAVE-3.

## S08. Диалоги и уведомления

Все в стиле сайта, без системных `confirm` и `alert`. Разметка и фокус — [responsive-a11y.md](responsive-a11y.md).

| Окно | Когда | Содержимое и кнопки |
| --- | --- | --- |
| Заменить или добавить | Отправка пожелания при непустом плане (R-WISH-7), показывается на S07 | `dialog.replace.*`: «Заменить план», «Добавить в ‹активный день›», «Отмена» |
| Другое место | «Заменить» у места (R-REPL-1) | Поле `replace.search`, список мест, `replace.empty`, «Отмена» |
| Очистить план | `plan.clear` | `dialog.clear.*`: «Очистить», «Отмена» |
| Убрать второй день | R-DAYS-2 | `dialog.days.*` |
| Загрузка файла | Файл выбран, план не пуст (R-SAVE-2) | `dialog.import.title`: «Заменить план», «Отмена» |
| Уведомление | Добавлено, убрано, перенесено, лимит, ошибка | Одна область над нижней панелью; «Отменить», где применимо; 8 с, пауза при фокусе и наведении (R-DEL-2) |

## S09. Не найдено

- Неизвестный `idea` или `route` в адресе — `notFound.idea` / `notFound.route` и кнопка в соответствующий каталог.
- Неизвестный `place` — S06 без подсветки.
- Неизвестный `view` — главная.
