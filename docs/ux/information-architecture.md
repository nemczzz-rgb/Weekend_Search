# Информационная архитектура

## Карта сайта

```
Главная (S01)
├─ Идеи для дня (S02) ──► Идея для дня (S03)
├─ Маршруты (S04) ──────► Маршрут (S05)
├─ Места (S06), сверху — «Ближайшие события»
└─ Мой план (S07)
   Общие окна: диалоги и уведомления (S08); «не найдено» (S09)
```

## Названия (D15)

| Сущность | Данные | В интерфейсе |
| --- | --- | --- |
| Сценарий дня из 2–3 занятий | `day-ideas.json` | «Идея для дня», раздел «Идеи для дня» |
| Городская подборка из 1–6 мест | `routes.json` | «Маршрут», раздел «Маршруты» (раньше «Идеи») |
| Место | `places.json` | «Место», раздел «Места» |
| Событие | `events.json` | «Событие», блок «Ближайшие события» в «Местах» |
| Занятие | `activities.json` | «Занятие» — часть идеи для дня и пункт плана |
| Пункт плана | `PlanItem` | «Пункт»: в сводке «3 пункта», а не «3 места» |

Слово «Идеи» без уточнения в навигации не используется. Заголовок раздела маршрутов — «Маршруты по городу».

## Меню

- Порядок: **Идеи для дня · Маршруты · Места · Мой план** (вопрос 3).
- От 768 px — в шапке, как сейчас, рядом с подписью «МОСКВА / WEEKEND GUIDE». Логотип ведёт на главную.
- До 767 px — нижняя плавающая панель из четырёх пунктов. Подпись «Идеи для дня» может переноситься на две строки. Если в макете при 360 px область нажатия любого пункта меньше 44 × 44 px, применяется запасной ход: «Маршруты» и «Места» объединяются в пункт «Город» с вкладками «Маршруты | Места» внутри (вопрос 2). Запасной ход касается только нижней панели: пункт «Город» открывает `?view=routes`, а на S04 и S06 до 767 px сверху появляется переключатель «Маршруты | Места». Адреса экранов не меняются, шапка от 768 px остаётся из четырёх пунктов. Решение принимается на приёмке макетов (TASK-042) и записывается сюда.
- Активный пункт отмечен как сейчас (фон-пилюля) и `aria-current="page"`.

## Адреса экранов (P7)

Только query-параметры, без путей. Пустой адрес = главная.

| Экран | Адрес | Параметры |
| --- | --- | --- |
| S01 Главная | `?view=home` или пусто | — |
| S02 Идеи для дня | `?view=day-ideas` | `mode` = `home` · `city` · `mixed`; `for` — одно или несколько через запятую: `for=pair,friends` (`solo`, `pair`, `friends`, `family`); `time` = `short` · `medium` · `long` |
| S03 Идея для дня | `?view=day-ideas&idea=<id>` | `genre=<GenreId>` — выбранный жанр |
| S04 Маршруты | `?view=routes` | `theme=<тема>`, `q=<поиск>` |
| S05 Маршрут | `?view=routes&route=<id>` | — |
| S06 Места | `?view=places` | `q=<поиск>`, `place=<id>` — прокрутить к месту |
| S07 Мой план | `?view=plan` | `day=1` · `2` |

- Переход между экранами (смена `view`, открытие `idea` или `route`) — новая запись в истории браузера (R-NAV-1). «Назад» возвращает на предыдущий экран с его фильтрами и позицией прокрутки.
- Изменение фильтров, поиска, жанра и дня — замена текущей записи без новой (кнопка «Назад» не «отматывает» фильтры).
- Текст пожелания в адрес не попадает (вопрос 6).
- Раскрытые блоки рецепта и выбранный фильм в адрес не попадают; фильм хранится в пункте плана.
- Неизвестное значение параметра игнорируется; неизвестный `idea` или `route` — экран S09.
- Источник перехода для ссылки «←» хранится в `history.state`, не в адресе (R-NAV-2).

## Главная (S01): состав сверху вниз

1. Постер «Выходные в Москве» с башней — как сейчас.
2. Описание: новый текст, где упомянуты идеи для дня дома и в городе (см. [microcopy.md](microcopy.md)).
3. Две кнопки: **«Идеи для дня»** (главная) и **«Найти место»** (вторая).
4. **Компактное поле пожелания** в одну строку и 4 чипа-примера (эталонные фразы 8.3). Отправка открывает `?view=plan` с черновиком.
5. `01 / ИДЕИ ДЛЯ ДНЯ` — три карточки идей: по одной с `mode` home, city и mixed, первые по порядку в `day-ideas.json` (вопрос 13). Кнопка «Все идеи для дня (N)».
6. `02 / МАРШРУТЫ` — три первых маршрута, кнопка «Все маршруты (N)».
7. Подвал.

Пока в `day-ideas.json` меньше одной идеи нужного вида, соответствующая карточка не показывается; если идей нет совсем, блок 5 скрыт.
