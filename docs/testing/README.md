# Проверка качества

Критерии AC-01–12 определены в [ТЗ](../project/technical-specification.md). Для приложения выбраны pytest, Vitest и Playwright; настройка после TASK-003. До контрольной точки допустимы отдельные диагностические проверки без зависимостей приложения.

Общие и сквозные проверки смогут находиться в [tests](../../tests/README.md), а проверки отдельных модулей — рядом с кодом. При передаче работы нужно указывать реально запущенные проверки, результаты и непроверенные области.
