## Исправлено в этом PR

1. **S09 «Не найдено».** Неизвестный маршрут показывал блок без h1: заголовок для фокуса при переходе (R-NAV-1) отсутствовал. Неизвестная идея показывала «Идея не найдена» вместо `notFound.idea`. Теперь оба экрана используют `notFound.idea` / `notFound.route` в h1 и ссылки `notFound.toCatalog` / `notFound.toRoutes`.
2. **Рамка фокуса.** Она рисовалась цветом акцента, а у зелёного акцента контраст с фоном 2,59:1 при норме 3:1 (WCAG 1.4.11). Теперь `--ws-focus` использует `--ws-accent-text`: фиолетовый, синий и сиреневый остаются своим цветом, остальные акценты получают чернильную рамку. Для всех 9 акцентов контраст не ниже 6:1.
3. **Форма «Свой пункт».** По S07 кнопка с пустым названием должна быть неактивной, а она выглядела активной. Теперь кнопка оформлена как неактивная через `aria-disabled`, но остаётся доступной по Tab; при отправке пустой формы появляется подсказка «Напишите название».
4. **Тест прошедших событий.** Для AC-DI-11 не было теста с подменой даты. Добавлен `tests/web/events-dates.test.mjs`, он включён в CI.

## Замечания без исправления

- Нажатая кнопка с чернильным текстом на зелёном и оранжевом акцентах: контраст 4,17:1 и 3,60:1. Это краткое состояние нажатия, обычная кнопка проходит (6,17 и 5,33). Если нужно строго 4,5:1 и в этом состоянии, цвета `--ws-accent-pressed` меняет дизайн.
- Заголовок плана после домашнего черновика «хочу весь день дома» — «Мой план». Так задумано (`wish.ts`): черновик собран не из одной целой идеи, поэтому `sourceTitle` не ставится.
