## Проверка и хранение

Точные TMDB ID взяты из P4947 тех же версий объектов Wikidata, которые указаны в [журнале фильмов](film-research.md). Для всех 150 объектов найден ровно один неустаревший ID. Открыты публичные карточки TMDB с русским языком, извлечены изображение из элемента poster и метаданные Movie (название, дата). API-ключи, вход в аккаунт и платные сервисы не использовались. Изображения получены с CDN TMDB по ссылкам карточек, проверены декодированием и сжаты в WebP без обрезки пропорций; все 150 просмотрены на контактных листах.

У трёх карточек отличается год TMDB: «Отель „Мэриголд“. Лучший из экзотических» — 2012 / в базе 2011; «Запределье» — 2008 / 2006; «Африканская королева» — 1952 / 1951. Год и источник фильма не заменялись датой локального проката TMDB. «Запределье» дополнительно сопоставлено по режиссёру Тарсему Сингху; [BBFC](https://www.bbfc.co.uk/release/the-fall-restored-cut-q29sbgvjdglvbjpwwc0xmdi1njq1) также относит фильм к 2006 году.

У «Дня, когда остановилась Земля» (1951) русское изображение TMDB было ошибочным постером ремейка 2008 года с Киану Ривзом. Оно отброшено при визуальной вычитке; выбран английский постер оригинала из той же карточки (language=en-US). Английский постер сохранён и там, где русского варианта не было. Другие версии фильмов, кадры, фотографии актёров и заглушки вместо постеров не подставлялись.

Локальные пути — images/films/<film-id>.webp внутри public/. Ссылки в интерфейсе составляются с import.meta.env.BASE_URL, без ведущего слеша; JSON не встраивает изображения в JS. Поля width/height резервируют пропорции, loading="lazy" и decoding="async" нужны для изображений вне первого экрана. В журнале ниже сохранены исходные URL и SHA-256 сжатых файлов для повторной сверки.

## Атрибуция и интерфейс TASK-049

- Для каждого постера сохранены source, credit: TMDB и checkedAt. Рядом с блоком фильмов должна быть видимая подпись «Постеры: TMDB» со ссылкой на https://www.themoviedb.org; источник конкретного постера доступен из карточки. Это метаданные изображения, а не ссылка на просмотр.
- В разделе источников/об авторах использовать [официальный логотип TMDB](https://www.themoviedb.org/about/logos-attribution) и заметную формулировку из [правил атрибуции](https://developer.themoviedb.org/docs/faq): “This product uses the TMDB API but is not endorsed or certified by TMDB.” Она предусмотрена правилами поставщика данных/изображений; получение этой пачки выполнено с публичных страниц, без API.
- [FAQ TMDB](https://developer.themoviedb.org/docs/faq) предусматривает бесплатное некоммерческое использование с атрибуцией. Изображения не объявляются CC0 и не включаются в свободную лицензию собственного кода. Права на постеры принадлежат соответствующим правообладателям.
- Экран фильмов ещё не реализован: добавлены данные, локальные изображения и требования для TASK-049. При отсутствии или ошибке файла показывать текст «Постер недоступен», сохраняя название, год и кнопку выбора; не выдавать иллюстрацию за постер. Фильм без poster остаётся допустимым по схеме для совместимости, но все текущие 150 записи имеют poster.
