## Метод

Прочитаны аннотации Movie.description из уже полученных в этой сессии публичных карточек TMDB для всех 150 конкретных фильмов. Сопоставление названий, годов и ID выполнено в [журнале метаданных](film-research.md) и [журнале постеров](film-posters.md). Краткие русские тексты «Контакта», «Реквиема по мечте», «До встречи с тобой», «Арахисового сокола», «Ведьминой службы доставки» и «Рождественской истории» дополнительно сверены с полными английскими карточками. Для 8 описаний использованы прочитанные страницы студий/дистрибьюторов, перечисленные в таблице.

Аннотации пересказаны заново: на сайте хранится только краткая завязка своими словами, исходные тексты и их переводы целиком не копируются. noteSource и noteCheckedAt относятся именно к описанию; source/checkedAt фильма по-прежнему подтверждают название и год, poster — изображение. Это не отзыв о личном просмотре, не оценка возраста и не утверждение о доступности на платформах.

Поиск уточнений: страницы Warner Bros для «Контакта» и Lionsgate для «Реквиема по мечте» не дали читаемого описания и не используются как noteSource. Для «Нового кинотеатра „Парадизо“» прочитана более полная аннотация Miramax о дружбе мальчика с киномехаником; для «Невероятной жизни Уолтера Митти» — завязка путешествия на странице 20th Century Studios. Факты из непроверенных результатов не переносились.
