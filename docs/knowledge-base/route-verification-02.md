## Что остаётся блокером

- Не все конкретные входы и возможные закрытые проходы проверены. Overpass вернул таймаут/502; через основной OSM API найдены main-входы обоих музеев (см. ниже). У кафе и галереи остаются маркеры, временные ограждения/проходы на месте не проверены.
- У кафе не подтверждены все условия брони и актуальное наличие выбранных блюд. Средний чек и пример заказа — разные виды ориентира. У «Сока» депозит в сб–вс 13–19 и правила для группы от восьми человек требуют уточнения; его не считаем дополнительной фиксированной платой без правил зачёта.
- Болотная площадь и имеющийся id=bolotnaya (набережная) — разные точки. Для исходной версии при переносе понадобится отдельная запись площади; подменять существующий id набережной не нужно. Начало уже задано исходным кандидатом issue #45.
- Требуется выбор/утверждение владельца по issue #45 до переноса кандидатов в рабочую базу. Эти материалы не превращают весь проект из 50 маршрутов в принятые прогулки.

В рабочем каталоге обновлены только price у tretyakov и mmoma-petrovka с source/checkedAt. Ни одного маршрута или события не изменено. Копии чужих страниц и изображений в репозиторий не добавлялись: только собственное изложение проверенных фактов, ссылки и ограниченный набор результатов расчёта.

- Маркер «Сока» → основной вход Третьяковки: 111,4 м / 89,1 с; смещение конца 0 м (старый расчёт до центра — 287,2 м).

Источники: [здание ММОМА](https://api.openstreetmap.org/api/0.6/way/47138172/full.json), [комплекс Третьяковки](https://api.openstreetmap.org/api/0.6/relation/1907261/full.json), конкретные node и URL расчётов — в JSON доказательств. Предыдущие расчёты сохранены как previousCalculation, чтобы не скрывать причину изменения. Таким образом, актуальных отрезков шесть; два из них теперь ведут к картографически обозначенным главным входам. Это всё ещё не означает проверки двери каждого кафе или временных ограждений.

У здания Солянки API показал жилые лестничные входы; их нельзя автоматически назначать входом галереи. Данные жилых квартир и имена авторов правок не включены в сводку. Официальное указание «вход с Забелина» и карта галереи сохранены отдельно.
