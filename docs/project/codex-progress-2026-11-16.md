## Важные границы исследования

- 100 мест — объём подготовленного объединения #62, в main пока 45. Отдельные пачки конфликтуют по общим файлам, поэтому их уже свели в #62 с сохранением коммитов. Не сливать их снова по отдельности.
- Часть старых publicSpace не имеет отдельно подтверждённых адресов/часов/цен. Источники ВДНХ/Останкино недоступны; даты проверки не освежены искусственно. У канатной дороги/альпак противоречивые часы. Средний чек не выдаётся за обязательный расход, часы кассы — за расписание спектакля.
- Учтены перекрытие главного входа/партера Парка Горького, закрытие Парка неба планетария на 2026 год, временная реэкспозиция AZ до 19 ноября, изменения правил ГЭС-2 с декабря без их преждевременного применения. Доступность билетов/бронь не обещана.
- Четыре пеших отрезка рассчитаны по открытым картографическим данным. Точки привязки не являются проверенными дверями; нет физического осмотра, подтверждения текущих ограждений или готовности всех 50 прогулок.
- TASK-047 готова в redesign (#61), поэтому прежнего технического блокера TASK-049 больше нет. В #65 включены эта логика и #63 обычным merge. По исходному процессу пользователя PR — в main; общего выпуска без разрешения не было.
