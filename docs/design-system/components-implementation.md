# Компоненты TASK-048

Контролируемая библиотека в `apps/web/src/ui/components.tsx`, строки в `copy.ts`, стили в `ui.css`. Витрина: `ui-preview.html` (при Pages — `/Weekend_Search/ui-preview.html`); текущие экраны не переключены на новый дизайн. Сборка содержит обе входные страницы. Модель и вращение башни не менялись.

## Состав и подключение

- Logo, Header, BottomNav, Footer, AccentPalette — оболочка и девять акцентов.
- Eyebrow, PageHeading, Button, FilterChip, Segmented, Field, WishInput — ввод и выбор; подписи, подсказки и ошибки связаны с полями.
- StatusBadge, IdeaCard, RouteCard, PlaceCard, SourceFacts, Accordion — карточки и подтверждённые факты. Дата — самая ранняя среди показанных фактов, включая адрес; неизвестное не получает отметку проверки.
- FilmChoice, RecipeBlocks — настоящий локальный постер с запасным состоянием, собственное мини-описание со ссылкой на источник, рецепт со всеми авторскими разделами и количествами.
- AddToDay, IdeaSummary, PlanDayCard, PlanItemCard, EveningDivider, StorageBar — представление действий и состояний. AddToDay получает различимые состояния через union props; владелец экрана выполняет callbacks.
- Banner, Dialog, Toast, Skeleton, EmptyState, LoadError — обратная связь и ошибки. Dialog — native dialog с начальным фокусом на отмене, удержанием и возвратом фокуса, Escape.

Компоненты не читают JSON и localStorage, не реализуют вторую модель плана. Типы контента импортируются из существующего контракта. Интеграция с loader/store TASK-047 и сохранение акцента — задача хоста TASK-049/050. Данные фильма и рецепта витрины — точные снимки двух записей; тест сравнивает их с текущим контентом. Демонстрация не сохраняет план и прямо называет результат примером.

## Доступность и решения

Девять компактных цветных отметок собраны в одну кнопку открытия палитры; внутри каждый выбор имеет область 44×44 px, имя и aria-pressed. Это сохраняет компактный вид шапки и делает выбор доступным на телефоне. Escape закрывает панель и возвращает фокус. Сегментированный переключатель поддерживает стрелки, Home и End.

Маленький текст при светлых акцентах использует чернила; фокус виден отдельно от цвета, выбранные карточки подняты и имеют рамку/подложку по PR #59. Загрузка статичная, reduced-motion убирает переходы. Четыре пункта нижней панели проверены на 360 px, название «Идеи для дня» сохраняется.

Inter Tight и Onest размещены локально с OFL. Manrope для текущего приложения также перенесён локально; удалены внешние запросы шрифтов. Старые стили ещё нужны старым экранам и удаляются после их переноса в TASK-050.

## Проверено 16.11.2026

Все команды tests/README.md: установка с frozen lockfile, валидатор, 65 негативных проверок, Pages-сборка, тесты фона/дат/компонентов и 18 unittest — успешно. Новая SSR-проверка компонентов включена в CI, без новых production-зависимостей.

Проверены отсутствие горизонтальной прокрутки, четыре пункта навигации ≥44 px, клавиатура, диалог и возврат фокуса, ввод пожелания, смена акцента, исходные 390 г воды в рецепте, reduced-motion, сохранение карточки при 404 постера и работа прежней главной с локальным Manrope.
