# Компоненты

- Статус: утверждено Alex071004 13.11.2026 ([ADR-006](../decisions/ADR-006-visual-refresh.md)).
- Перечень взят из [brief/components.md](brief/components.md). Разметка и стили — [design/claude-design/project/ws.css](../../design/claude-design/project/ws.css), примеры — экраны S01–S09 и артборды «Кнопки и поля» и «Карточки».

## Карточки

| Компонент | Спецификация |
| --- | --- |
| Карточка | Белая, рамка 1,5 px чернилами, радиус 4 px, внутренний отступ 18–20 px (16 на телефоне). Наведение: сдвиг −2 px и подложка 4 px акцентом |
| Карточка идеи | Рубрика («Дома · одному, вдвоём»), заголовок 26 px, описание 14 px, время, «Понадобится: … и ещё N», статус, «Открыть →». Вся карточка — одна ссылка. Иллюстрация 3:2 сверху, когда у записи есть `image` |
| Статус «сегодня» | Три значения: «Можно сегодня» (`--ws-tint`, галочка), «Лучше в другой день» (белый, рамка, календарь), «Начать за 2–3 дня» (чернила, белый текст, часы, причина вторым абзацем). Значок и текст везде |
| Карточка маршрута | Рубрика «Тема · 1 день», заголовок, подзаголовок, места через «·», «Район · N мест», «Открыть маршрут →» |
| Карточка места | Номер (только в маршруте), «Вид · район», название, описание, адрес-ссылка ↗, плашка фактов «Часы» и «Стоимость» на `--ws-tint`, «Источник ↗», «Проверено …», «Около N мин», «В план +». Без фактов: «Уточнить перед визитом», «Найти на карте ↗» |
| Сводка идеи | 1280 px, липкая справа, 380 px: для кого, время, статус, «Что понадобится», кнопка и строка R-TODAY-4 |

## Идея для дня

Раскрывающиеся блоки рецепта (кнопка-заголовок, `aria-expanded`, значок «+» или «–» акцентом), ингредиенты с примечаниями, нумерованные шаги, жанры чипами, строки фильмов (название, «год появится из базы», «Выбрать» / «Выбран ✓»), строка предупреждения под кнопкой.
