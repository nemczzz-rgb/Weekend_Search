# Дизайн-система

Раздел для будущих визуальных принципов, цветов, типографики, отступов, компонентов, состояний и правил доступности интерфейса.

Направление согласовано: светлый городской путеводитель, тёплый фон, тёмный текст, зелёный акцент, выразительная типографика, фотографии. Основной экран — диалог. Токены и компоненты создаются в TASK-005 по [плану](../project/implementation-plan.md); самих компонентов пока нет. Исходные материалы: [assets](../../assets/README.md).

Для «Идей для дня» владелица выбрала развитие утверждённого оформления без полной замены страниц. Решение согласовано обоими участниками: [ADR-005](../decisions/ADR-005-day-ideas-redesign.md). Снимок утверждённого оформления — [design/approved/](../../design/approved/README.md), он служит эталоном для аудита и приёмки макетов.
