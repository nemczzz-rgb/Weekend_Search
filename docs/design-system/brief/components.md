# Компоненты для макетов

Перечень компонентов, которые должны быть в дизайн-системе Claude Design (TASK-041). **С** — существует, воспроизвести по [current-tokens.md](current-tokens.md). **Д** — существует, доработать. **Н** — новый, в том же визуальном языке. Где используется — экраны из [screens.md](../../ux/screens.md), правила — из [interaction-rules.md](../../ux/interaction-rules.md).

Общие состояния интерактивных элементов: обычное, наведение, нажатие, фокус (`:focus-visible`), неактивное (`disabled`). Область нажатия — не меньше 44 × 44 px.
