- Доступны два типа:
  - **Design** — холст с артбордами;
  - **Design System** — дизайн-система.

**Рекомендация:**
1. Сначала создать дизайн-систему **«Weekend Search»** из типа Design System по [current-tokens.md](current-tokens.md) и снимкам `docs/ux/audit/`.

## Промт

Скопировать целиком:

```text
Ты дизайнер сайта Weekend Search — идеи на выходные в Москве: идеи для дня дома и в городе,
маршруты, места и личный план дня. Сайт уже есть и утверждён; задача — РАЗВИТЬ его, а не
перерисовать (решение ADR-005).

Приложены: current-tokens.md (токены текущего дизайна, снятые с живого сайта), components.md
(список компонентов и состояний), content-samples.json (реальные данные), screens.md,
microcopy.md, interaction-rules.md, responsive-a11y.md, content-rules.md (UX-спецификация)
и 14 снимков текущего сайта (390 и 1280 px).

ШАГ 1. Дизайн-система «Weekend Search».
Воспроизведи текущий визуальный язык по current-tokens.md и снимкам: бумага #f5f4f1,
чернила #191821, muted #595663, акцент #3932bd, крупные гротескные заголовки с плотным
трекингом, моноширинные рубрики «01 / …», курсивные номера, звёздочка ✳, полупрозрачные
карточки с мягкой тенью поверх фона с Шуховской башней, пилюли для меню и чипов.
Менять токен можно только с обоснованием: контраст WCAG AA, читаемость, нехватка состояния.
Обязательно:
- убрать зеленоватые оттенки текста — наследие старой темы (перечислены в current-tokens.md);
- поднять мелкие кегли: текст не меньше 12 px, кнопки не меньше 13 px;
- сделать кнопки пункта плана и чипы высотой 44 px;
- рамкам полей ввода дать контраст не меньше 3:1.
Шрифты — только свободные (OFL), из тех, что уже есть в дизайне. Сейчас реально видны
Manrope, Arial, Georgia и Consolas. Если предлагаешь замену Arial, Georgia или Consolas на
OFL-шрифт, покажи сравнение и обоснуй.

ШАГ 2. Компоненты.
Все компоненты из components.md со всеми перечисленными состояниями. Помеченные «С»
воспроизведи, «Д» доработай, «Н» создай в том же языке. Каждый интерактивный элемент —
не меньше 44 × 44 px, видимый фокус, статус — текстом и значком, не только цветом.

ШАГ 3. Экраны.
Все экраны S01–S09 из screens.md на 390 и 1280 px. Тексты — строго из microcopy.md.
Данные — только из content-samples.json:
- главная идея — «Римская пицца под киновечер» с рецептом и предупреждением
  «тесто 48–72 ч в холодильнике»;
- смешанная идея — «„Зарядье“ и римская пицца дома»;
- городская идея — «Сад, бульвар и пруды»;
- самый длинный заголовок — «Фруктовый салат и история в картинках».
В базе 150 фильмов. Для макета жанров используй films из content-samples.json:
проверенные названия, годы и poster. Файлы постеров — apps/web/public/images/films/;
если нужный файл не приложен к макету, явно покажи «Постер недоступен», не воссоздавай
его генерацией. Разрешение Alex071004 от 13.11.2026 отменяет прежний запрет постеров;
источник и атрибуция — по R-FILM-4 и docs/knowledge-base/film-posters.md.
Ничего не придумывай: ни адресов, ни цен, ни часов, ни фильмов, ни постеров, ни ссылок
на онлайн-кинотеатры.

Обязательные состояния:
- пустой план;
- домашний день без адресов и без «Старт в районе»;
- смешанный день с рубрикой «ВЕЧЕРОМ ДОМА»;
- два дня;
- строка подготовки над днём;
- прошедшее событие;
- лимит 6 пунктов;
- все состояния кнопки «В мой день» (interaction-rules R-ADD-7);
- маршрут на два дня;
- устаревший план;
- диалоги S08;
- уведомление «Убрано · Отменить»;
- пустые результаты фильтров;
- загрузка и ошибка загрузки;
- S09.
Нижняя панель на 360 px — 4 пункта с подписью «Идеи для дня» в две строки. Если
область нажатия любого пункта меньше 44 px, покажи запасной вариант «Город»
(information-architecture.md).

ШАГ 4. Арт-направление иллюстраций.
Стиль иллюстраций к идеям для дня в языке сайта: палитра, линия, плотность, пропорция 3:2.
Дай 3 эскиза: домашний вечер с пиццей, прогулка по саду, творчество дома.
Запрещено: реальные люди, логотипы, бренды, постеры фильмов, фотореализм, узнаваемые
кадры из фильмов. Файлы потом сделает другой исполнитель: WebP 640 и 1280 px, до 300 КБ.

Формат сдачи:
- артборды с именами вида «S03 Идея — 390», «S03 Идея — 1280», «S07 План — домашний
  день — 390»;
- отдельный артборд «Изменения токенов»: таблица «было → стало → почему»;
- отдельный артборд «Арт-направление».
```
