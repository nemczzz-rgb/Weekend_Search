# Текущие токены утверждённого дизайна

- Источник — **вычисленные стили** опубликованной сборки `main` (коммит `52a481c`), снятые в безголовом Chrome 2026-11-13 на 1280 и 390 px. Это то, что пользователь видит на самом деле, а не правила трёх слоёв CSS, которые перекрывают друг друга.
- По ADR-005 это **основа дизайн-системы**. Значение можно менять только с обоснованием: контраст AA, читаемость, нехватка состояния. Каждое изменение перечисляется в таблице отличий при сдаче макетов (TASK-041).
- Эталон кода — `design/approved/web/`, снимки экранов — `docs/ux/audit/`.

Они выбиваются из палитры «бумага, чернила, фиолетовый», и в новой системе их быть не должно.

## Приёмы, которые сохраняем

- Постер из двух строк разного цвета.
- Редакционная нумерация: «01 / ПОДБОРКИ», номера мест и пунктов курсивом.
- Звёздочка ✳ после заголовка страницы и в логотипе.
- Полупрозрачные карточки поверх башни.
- Плашки фактов «Часы / Стоимость» с источником и датой проверки.
- Нижняя плавающая панель на телефоне, пилюля активного пункта.
