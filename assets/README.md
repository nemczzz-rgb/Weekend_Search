# Исходные материалы

Здесь будут храниться согласованные исходные изображения, иконки и другие материалы проекта. Файлы, предназначенные для раздачи приложением, размещаются по правилам выбранного фреймворка после его согласования.

Для сторонних материалов фиксировать источник и условия использования. Не добавлять материалы с персональными данными или неясными правами.
