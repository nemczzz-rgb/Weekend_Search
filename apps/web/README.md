# Фронтенд Weekend Search

Интерфейс на React, TypeScript и Vite с 34 идеями и 45 местами. Каталог поддерживает поиск по названию и адресу, тематические фильтры и добавление в план. У мест есть описание, адрес со ссылкой на Яндекс Карты, режим и ориентир стоимости. Данные о посещении собраны в `src/visit.ts`; источники и дата проверки показываются в карточке. В плане доступны один или два дня, перестановка, замена, удаление, перенос и добавление своей точки с адресом.

Главная, каталог и план используют общую палитру, стеклянные поверхности и векторную решётку Шуховской башни. На главной при прокрутке меняется перспективный угол решётки.

## Запуск

На Windows один раз создать локальный сертификат. Его закрытый ключ и пароль сохраняются в `%LOCALAPPDATA%\WeekendSearch\https`, вне проекта и Git:

```powershell
pwsh -NoProfile -File scripts/local-https/setup.ps1
```

Команду выполнять из корня проекта. Для открытия без предупреждения браузера можно добавить **только этот сертификат** в доверенные сертификаты текущего пользователя Windows командой с `-Trust`; Windows может запросить подтверждение. Пользователь отказался от этого шага, поэтому сейчас сертификат не доверен. Не обходить предупреждение браузера. Доверие на телефоне настраивается отдельно.

```powershell
pwsh -NoProfile -File scripts/local-https/setup.ps1 -Trust
```

Затем из `apps/web/` открыть два варианта локального просмотра:

```powershell
pnpm install
pnpm dev
pnpm dev:https
```

`pnpm dev` даёт рабочий адрес `http://127.0.0.1:5173/` для совместной правки. `pnpm dev:https` даёт `https://127.0.0.1:5174/` или `https://localhost:5174/`; без доверия сертификату обычный браузер предупреждает о нём, а встроенный браузер Codex не открывает страницу. Проверка сборки: `pnpm build`. Требуется Node.js и pnpm. В `pnpm-workspace.yaml` разрешён установочный скрипт только для `esbuild`, необходимого Vite. Сайт остаётся доступным только на этом компьютере; для домашней сети и физического телефона потребуется отдельная настройка сертификата и запуска.

## Граница прототипа

Демо использует статическую подборку. Часы, сеансы и цены могут меняться, поэтому карточки ссылаются на источники. Если данных недостаточно, карточка предлагает уточнить их перед визитом. Карты открываются по внешним ссылкам. Встроенная карта, расчёт времени в пути и сохранение плана после перезагрузки относятся к дальнейшей работе.

Предпросмотр готовой сборки из корня проекта:

```powershell
pnpm --dir apps/web build
pnpm --dir apps/web preview --port 5175
```
