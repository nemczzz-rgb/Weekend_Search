# Утверждённый дизайн

Это зафиксированная пользователем версия сайта на 12.11.2026. Её исходники находятся в `web/`. Основа снимка — коммит `d92f63d11fea446d21485a2ae275090f7647d2b2` ветки `main`.

Папку `web/` не редактировать. Новые варианты размещать в `design/iterations/`; рабочее приложение остаётся в `apps/web/`. Дизайн меняется в отдельной ветке и попадает в `main` только после просмотра и согласия пользователя.

Большой файл `moscow-collage.png` не дублируется. Его точная версия хранится в Git-объекте `d4d5a5dc834eaff04b088770e00c167430e06438` исходного коммита. Для восстановления всей утверждённой версии достаточно этого коммита.

Чтобы вернуться к ней, сначала сохранить текущие изменения в отдельной ветке. Затем в новой ветке скопировать `design/approved/web/` в `apps/web/` и восстановить изображение из коммита выше. Проверить сборку и показать результат пользователю до merge. Не применять `reset --hard` к рабочей папке.
