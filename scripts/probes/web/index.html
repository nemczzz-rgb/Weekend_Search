Диагностическая страница бесплатного ключа Яндекс Карт. Это проверка интеграции, а не готовое приложение.

Настройка проверки

Ключ передаётся SDK Яндекса в браузере. Страница не отправляет его локальному серверу и не сохраняет. Для смены ключа перезагрузите страницу.

Результат

Живая проверка

Проверка ещё не запускалась. Без ключа успешный результат не выставляется.

  • Карта: не проверена
  • Пешеходный маршрут: не проверен
  • Общественный транспорт: не проверен

В отчёте только статусы проверок. Ключ, геометрия и ответы провайдера в него не входят. Эмуляция телефона не подтверждает проверку физического устройства.
