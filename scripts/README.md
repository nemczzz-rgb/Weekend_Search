# Служебные команды

Здесь находятся повторяемые команды проверки и сопровождения. До основной реализации добавлены [диагностические инструменты TASK-003](probes/README.md): KudaGo, Codex App Server и страница карты/проезда для компьютера и физического телефона. Это не приложение и не закрытие последующих задач.

У каждого добавленного скрипта должны быть понятное назначение, способ запуска и описание необходимых переменных окружения без секретов. Команды, меняющие внешние ресурсы, должны явно описывать своё действие.
