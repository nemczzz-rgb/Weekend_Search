# Контекст Weekend Search

Переносимая отправная точка для агента или аккаунта. Утверждённое ТЗ: [technical-specification.md](docs/project/technical-specification.md). Порядок реализации: [implementation-plan.md](docs/project/implementation-plan.md). Фактический статус: [memory/CURRENT.md](memory/CURRENT.md).

## Подтверждённый продукт

Бесплатное локальное демо для жителей Москвы: диалог с помощником, автоматический каталог и индивидуальные маршруты на один или два дня из мест и событий. Район задаёт начало; маршрут может выходить за его пределы. Перемещения — пешком и на общественном транспорте с реальным расчётом внутри сайта.

Пользователь добавляет свои точки, удаляет, заменяет, меняет порядок и переносит посещения между днями. Приложение пересчитывает расписание, сохраняет ручные изменения и показывает конфликты.

Аккаунт сайта необязателен. Гостю доступен текущий черновик, с аккаунтом — личные сохранённые маршруты. Телефон и компьютер владельца используют одну SQLite через локальный сервер в домашней сети. У самостоятельных участников отдельные экземпляры и собственные аккаунты Codex; независимые базы автоматически не синхронизируются.

## Утверждённые решения

- Фронтенд: React, TypeScript, Vite.
- Бэкенд: Python, FastAPI, Pydantic 2; SQLite.
- Помощник: локальный Codex App Server через Python и stdin/stdout. Модель и поиск требуют интернета и лимита аккаунта.
- Источник мест и событий: KudaGo API; обновление раз в шесть часов при работающем сервере.
- Карта и проезд: локальный выпуск с OpenStreetMap как направлением проверки; конкретный движок пешего и общественного проезда ещё не подтверждён. Бесплатный Яндекс API исключён для локального сценария по его условиям. Подробности: [ADR-003](docs/decisions/ADR-003-local-map-reassessment.md).
- Интерфейс: сначала диалог, затем результат с планом и картой; дополнительная форма пожеланий.
- Стиль: светлый городской путеводитель, спокойные цвета, выразительная типографика, фотографии.
- Бюджет: 0 рублей дополнительных платежей. Бесплатные аккаунты и ключи разрешены; платные API и автосписания исключены.
- Основной выпуск: локально и в домашней сети. По отдельному поручению от 2026-11-10 разрешена публичная статическая копия интерфейса для друзей через Sites; это не публикация Python/SQLite и не завершение интеграций. Подробности: [public-sharing.md](docs/project/public-sharing.md).

## Разрешённая работа

Пользователь явно утвердил полный план и поручил реализацию. Сначала фиксируем ТЗ (TASK-002), затем проверяем интеграции (TASK-003). Основная разработка TASK-004–013 начинается только после полного успеха TASK-003, включая ограничения инструментов и физический телефон. Скрипты проверки разрешены до этой точки. Непроверенное не заменять демонстрационными результатами.

## Основные принципы

1. Контекст доступен без истории старых чатов.
2. У факта одно основное место: ТЗ, статус, задачи, решения или история.
3. Предложение, документированная возможность и реально пройденная проверка имеют разные статусы.
4. Изменение имеет владельца; пересечения файлов согласуются до параллельной работы.
5. Готовность подтверждается воспроизводимой проверкой.
6. Секреты и полные чаты не входят в память проекта.
7. Помощник на сайте отделён от агентов разработки: он не получает репозиторий, shell и личные коннекторы.
